# Evangalinmart

Evangalinmart is a grocery shopping web application built with Java, Spring Boot, Maven, Thymeleaf, and H2 Database.

## Features

- Buyer and seller registration and login
- Browse and search grocery products
- Add products to the cart and place orders
- View order history
- Sellers can manage products and orders
- Buyers can rate and review products

## Technologies Used

- Java
- Spring Boot
- Maven
- Thymeleaf
- H2 Database
- HTML and CSS
- Apache Tomcat 9

## Build

Run this command from the project folder:

```bash
mvn clean package
